# 07 — The reading page and the library breathe

**What to build:** The reading page reads as a page rather than a wall — more air
between paragraphs, headings that carry real weight, a narrower measure, and a top
bar that is not six competing icons. The library shows less on each card.

**Why:** The user's words: "the app still feels a lot cluttered and text heavy",
naming both the reading page and the library, with the reading page first.

**Blocked by:** 02, 03 — spacing can only be judged once real structure is on the page.

**Status:** done — verified 2026-08-22 on a Pixel 7

- [x] The reader's top bar keeps back, progress and one menu; the rest move inside it
- [x] Paragraph spacing, heading weight and line measure are retuned
- [x] Library cards drop the metadata that does not help a choice
- [x] Nothing regresses in dark mode, or at either end of the text-size slider
